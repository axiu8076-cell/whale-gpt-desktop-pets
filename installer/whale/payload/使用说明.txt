鲸鲸生活助手 · Windows 独立整合版 2026.10.16

安装（Windows 10/11，64 位 Intel / AMD）
1. 先将整个 ZIP 解压到普通文件夹。不要在压缩包里直接双击运行。
2. 双击“安装鲸鲸.cmd”，按窗口提示安装；无需管理员权限，也不用安装 Node、Python 或 Codex CLI。
3. 桌面打开“鲸鲸生活助手”或“鲸鲸操作台”。操作台可以看效果、触发条件和立即演示。

API Key 可留空，动作、硬件提醒和番茄钟仍能使用。
余额记账只使用同事自己的 DeepSeek 官方 Key；Windows 当前用户加密保存。
更换 Key / 开机启动 / 本机任务读取：开始菜单 → 鲸鲸生活助手 → 连接与启动设置。
API Key 的修改会重启鲸鲸。原账本和动作设置保留。
API 余额与 ChatGPT 月费订阅额度不同；余额差值是观测支出，并非每条请求的精确账单。

日常使用
拖动鲸鲸调整位置；右键菜单调整角色、大小、气泡、音效与记账功能。
操作台 → 实时状态 · 开关 · 番茄钟：设置生活提醒和计时。
待机静默偷吃米饭、坐任务栏休息；普通窗口置顶，前台全屏时让位。
安装默认使用独立桌面模式，关闭 Codex 也能陪伴。退出：托盘菜单，或开始菜单 → 退出鲸鲸。
若切为跟随 Codex 模式而看不到鲸鲸，请打开并恢复 Codex 窗口。

本机 Codex 任务状态
安装选项可关闭任务读取。开启后只在本机读取任务事件与时间，用于 15 分钟闲置提醒、30 分钟任务完成庆祝。
没有 Codex 或记录不兼容时显示未知，不编造任务状态；其他功能正常使用。
任务标题、对话正文和工具内容不会由新增任务读取器写入状态文件或上传。

可选双宠功能
本包安装鲸鲸，不安装 GPT 娘。鲸鲸可独立庆祝、吃文件、提醒和记账。
走过去递咖啡、GPT 娘光炮及 GPT 娘操作卡，需要支持 presence/activity/display-request 协议的增强版外部 GPT 娘运行；普通原版未必支持。
没装 GPT 娘时相关按钮不可用，实际删除动画自动使用鲸鲸吃文件。
真实删除依赖桌面原图标缓存，拿不到原位置就跳过。Shift+Delete、非桌面文件不会触发。
“立即演示”使用示例文件，不会删除任何实际文件。

卸载 / 修复
开始菜单 → 鲸鲸生活助手 → 卸载鲸鲸。默认保留密钥、设置和账本；可选择一并清除。
重复运行安装包可修复程序。默认安装位置：用户目录下的 .whale-companion。
此目录包含个人数据，请勿把安装后的目录转发他人；只转发原始 ZIP。
离线安装包含 Electron；余额查询需要联网。使用 Windows 自带 PowerShell，脚本可直接查看；如果单位策略禁止脚本，请交由 IT 审核，不要关闭安全设置。
